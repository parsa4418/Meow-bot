# meowie-bot (نسخه بله)
ربات میویی برای پیام‌رسان بله

## متغیرهای محیطی
- `BALE_TOKEN` : توکن ربات از @botfather بله
- `DATABASE_URL` : آدرس PostgreSQL (Supabase)
- `ADMIN_IDS` : آیدی عددی ادمین‌ها با کاما (با دستور «آیدی من» توی بات پیدا کن)
- `BALE_CONVERT_BOLD` : (اختیاری) پیش‌فرض 1؛ اگر بولد در بله خراب نشون داده شد 0 کن
